# JavaDwg — 超轻量纯 Java 2013 DWG 矢量看图与实地定位工具 (44 KB)

专为工程测绘与市政施工现场打造，采用纯 Java 2013 DWG 解析引擎与 OpenGL ES 2.0 硬件加速，APK 仅 **44 KB**。

## 📦 安装包下载
- 前往右侧 **[Releases (v2.0)](../../releases/tag/v2.0)** 页面直接下载 `app-release.apk` 安装使用。

## ⚠️ 核心配置要求
1. **SHX 字体**：请将西文字体与中文大字体（如 `txt.shx`、`HZ.SHX`）放入手机 `/sdcard/1hdm/` 目录。
2. **DWG 版本**：仅支持 **AutoCAD 2013 (`AC1027`)** 格式。
3. **权限与投影**：需授予文件与定位权限；同名 `.proj` 文件可用于自定义四参数转换。
