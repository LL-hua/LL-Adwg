# LL-dwg 使用说明

## 1. 准备数据目录
在手机内部存储根目录创建文件夹 `/sdcard/1hdm/`，放入以下文件（前缀名需与图纸一致）：
* **中文字体**：`HZ.SHX`（可选，未放置时英文、数字与标点仍可正常显示）
* **图纸文件**：`xxx.dwg`（需为 **AutoCAD 2013 DWG** 格式）
* **投影配置**：`xxx.proj`（UTF-8 纯文本，与图纸同名同目录，用于 GPS 经纬度转施工坐标）

---

## 2. `.proj` 坐标投影配置说明
支持 **高斯投影（`proj=gao`）** 和 **UTM 投影（`proj=utm`）**，填写投影类型、中央子午线及至少 2 个控制点（程序自动解算四参数），支持 `#` 注释。

### 控制点行格式
`经度(十进制度), 纬度(十进制度), X(北坐标N), Y(东坐标E)`（英文逗号分隔，南纬/西经填负数）

### 示例一：高斯投影（`proj=gao`）
```text
proj=gao
center=103
# 控制点格式：经度, 纬度, X(北坐标), Y(东坐标)
113.5081579, 22.7781009, 190357.814, 63064.717
113.4932591, 22.77336504, 189831.214, 61535.474
```

### 示例二：UTM 投影（`proj=utm`）
```text
proj=utm
center=33
# 控制点格式：经度, 纬度, X(北坐标), Y(东坐标)
32.50374233, -3.725201639, 9588533.76, 444814.013
32.50363908, -3.723555306, 9588715.735, 444802.432
32.49289606, -3.699971972, 9591321.926, 443608.008
```

## 3. 界面与手势操作
* **打开图纸**：点击底部「打开」，授予“所有文件访问权限”后选择 `.dwg` 文件。
* **视图缩放**：双指捏合缩放；**单指双击**局部放大；**双指轻点**局部缩小。
* **点捕捉查坐标**：点击底部「查点」开启捕捉模式，按住屏幕拖动，手指上方 **240px 黄色指示箭头**会自动吸附端点（`□`）与中点（`△`），底部显示 `N(北) / E(东)` 坐标及距当前 GPS 的平距与方位角，支持一键复制。
* **实地定位**：点击底部「定位」开启 GPS，图纸上实时显示当前位置与行进方向。
* **图层与显示**：点击底部「图层」或右上角「菜单」，可控制图层/图元显隐、切换黑白底色或微调字高。
