# JavaDwg — 超轻量纯 Java 2013 DWG 矢量看图与实地定位工具 (42 KB)

专为工程测绘、公路市政施工现场打造的超轻量级 CAD 看图软件。已彻底移除 Go 原生依赖 (`libcad.so`)，采用 **纯 Java 2013 DWG 二进制解析引擎 + OpenGL ES 2.0 硬件加速渲染**，安装包体积仅 **42 KB**，全架构通用。

## 📦 安装包下载

- **直接下载安装包**：前往本仓库 `release/JavaDwg-v2.0-release.apk` 下载并安装（支持 Android 7.0 及以上，全架构通用）。

## 📱 使用说明

1. **权限授予**：首次打开请授予**“所有文件访问权限”**（读取 `.proj` 与字体库）和**“位置信息权限”**。
2. **SHX 字体准备**：将所需的 `.shx` 字体文件（如 `txt.shx`、`HZ.SHX`）放入手机 `/sdcard/1hdm/` 目录，启动时自动加载（缺失时会有弹窗提示）。
3. **投影配置 (`.proj`)**：在与 `.dwg` 同级目录或 `/sdcard/1hdm/` 放置同名 `.proj` 文件即可自动解算施工坐标；未配置时默认按 UTM 投影计算。
